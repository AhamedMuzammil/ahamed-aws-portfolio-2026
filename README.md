# AWS S3 Static Portfolio Website Hosting

##  Project Overview

This project demonstrates how to host a static portfolio website using Amazon Simple Storage Service (Amazon S3).

The website is built using HTML and CSS and deployed through Amazon S3 Static Website Hosting.

##  Project Objectives

- Understand Amazon S3 and cloud storage.
- Create and configure an S3 bucket.
- Upload and manage website files.
- Configure bucket permissions and access control.
- Host a static website using Amazon S3.

##  Technologies & AWS Services Used

- **Amazon S3** – Cloud storage and website hosting.
- **HTML** – Website structure.
- **CSS** – Website styling.
- **AWS Bucket Policy** – Website access permissions.

##  Project Implementation

### Step 1: Create S3 Bucket
Created an Amazon S3 bucket to store the static website files.

### Step 2: Upload Website Files
Uploaded the `index.html` file to the S3 bucket.

### Step 3: Configure Permissions
Configured the required bucket permissions and public read access for website hosting.

### Step 4: Enable Static Website Hosting
Enabled static website hosting and configured `index.html` as the index document.

### Step 5: Access the Website
Accessed the deployed portfolio website using the S3 website endpoint.
